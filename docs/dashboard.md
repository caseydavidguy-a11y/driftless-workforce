# Driftless Workforce Command Center

The dashboard is designed around decisions, not vanity metrics.

## Primary view

1. **Pursue now** — strongest employer opportunities, sorted by score.
2. **Monitor** — promising employers without enough evidence to pursue yet.
3. **Low** — retain for history but do not spend outreach time.

Each prospect should expose:

- employer
- opportunity score
- hiring volume
- verified opening count
- target industries
- locations
- leadership openings
- current pipeline status
- next action

## Operating loop

The daily workflow is:

`refresh data -> detect changes -> rescore -> review Pursue -> research decision-maker -> contact -> record outcome`

The dashboard should make the next action obvious within seconds. It should not require opening raw JSON or CSV files.

## Product principle

The dashboard is an internal operating tool for Driftless Workforce. The public website can come later. The intelligence layer is the product foundation.
