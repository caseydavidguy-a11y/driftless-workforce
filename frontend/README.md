# Driftless Workforce Command Center

Open `index.html` to use the V1 browser interface. The production interface reads generated employer intelligence and alert data from the sibling `data/` directory in the deployed site artifact.

There is no production demo fallback. If live output is unavailable, the command center explicitly reports that the intelligence refresh has not populated the dataset yet.

`pipeline.html` provides the prospect workflow board. Employer intelligence is generated by the Python collector and published with GitHub Pages through the repository workflow.
